<h1>Prosjekt-i-datamaskinarkitekturh</h1>

<h2>Læringsutbytte:</h2>
<p>Dette prosjektet var veldig læringsrikt, med at jeg først fikk innføring i hvordan ulike komponenter i datamaskinen samhandler og fungerer. Gruppen vår fikk i oppgave om å se på hvordan busser fungerer i en datamaskin. Det var lærerikt å se hvordan ulike type busser samhandlet for at informasjonen fra ulike komponenter kunne fraktes til hverandre.</p>

<h2>Mitt bidrag:</h2>
<p>Jeg bidro med å finne nyttig informasjon om de ulike type bussene. Jeg lagde powerpointen vi brukte til å spille inn videoen og var med på å spille inn innholdet.</p>
